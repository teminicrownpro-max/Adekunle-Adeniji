2. **Work authorization.** Your resume doesn't state it. If you hold a work permit, PR or citizenship, consider adding one line (e.g., "Eligible to work in Canada") to the contact header. Several postings screen on it.
3. **Toronto roles (#2–#6) mean relocation or commuting.** The ROM Gallery Activation cover letter says you'd "welcome the chance to work on-site with your team in Toronto." Edit that if it doesn't hold.
4. **Names.** If you find the hiring manager's name (LinkedIn or the posting), replace "Dear Hiring Committee."
5. **Upload the PDF** unless a portal asks for Word. Keep file names as they are; they're recruiter-friendly.
6. **Track it.** Note the date applied, contact and follow-up date (7–10 business days).
